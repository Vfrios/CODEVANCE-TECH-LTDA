# Controle de versão — CodeVance Tech

## Versão 1.2

**Data de registro:** 08/10/2026  
**Período da implementação:** 07/10/2026 a 08/10/2026  
**Status:** Em validação; não publicada  
**Responsável:** Equipe CodeVance Tech  
**Branch ou commit:** `main` / commits de `6229ae6` a `bce1afb`; alterações locais ainda não commitadas

## Resumo

A versão 1.2 reúne a criação e a evolução do assistente virtual local do site, a limpeza de arquivos e configurações antigos e a reorganização do servidor Node para `src/index.js`. O chatbot responde perguntas frequentes, conduz o visitante por um briefing e prepara o WhatsApp com o resumo do projeto informado. O registro também inclui os ajustes feitos após os commits para garantir que os caminhos do servidor e da documentação correspondam à estrutura atual.

## O que foi implementado

### Assistente virtual e briefing

- Adicionado o componente `ChatAssistant.jsx` à página inicial, substituindo o botão flutuante anterior do WhatsApp como ponto de atendimento inicial.
- Implementadas respostas locais por regras e conteúdo predefinido, sem API, WebSocket ou provedor de IA.
- Criado fluxo progressivo de briefing para coletar tipo de solução, negócio/público, objetivo, recursos e prazo.
- Adicionadas sugestões clicáveis, indicador de digitação e tempo mínimo de espera para as respostas.
- Criados conteúdo contextual e respostas para dúvidas sobre serviços, planos, valores, processo, prazos e atendimento.
- Atualizados os textos de início de projeto e de atendimento para orientar o visitante a falar com a equipe.

### Encaminhamento para WhatsApp

- O atalho “Falar com a equipe” do chatbot monta uma mensagem com os dados do briefing já compartilhados.
- As sugestões de contato e as solicitações diretas para falar com a equipe abrem o WhatsApp em uma nova aba, em vez de apenas retornar uma orientação textual.
- Sem briefing preenchido, o link continua usando a mensagem padrão configurada em `src/config/site.js`.
- O formulário da página de contato e os demais links gerais de WhatsApp mantêm seus fluxos existentes.

### Servidor e estrutura do projeto

- Movida a entrada do servidor de `server/index.js` para `src/index.js`, conforme a reorganização da estrutura solicitada.
- Atualizados os scripts `dev:back`, `start` e `start:back` para executar `src/index.js`.
- Removidos a pasta `server/` e seus diretórios placeholder vazios.
- Transferido o contexto do chatbot para `src/features/layout/chatbot-context.md`.
- Removida a implementação anterior do fallback do chatbot após a adoção de `chatbotResponses.js`.
- Atualizados o proxy local do Vite, o README e a documentação técnica para refletir os novos caminhos.

### Limpeza de arquivos e documentação

- Removidos `DOCS/comp.txt`, `README copy.md` e `package-PC-Vitor.json`, que eram arquivos redundantes ou específicos de uma cópia local.
- Atualizados os metadados e as orientações de desenvolvimento no README.
- Ajustado o tipo de declaração para importar o contexto Markdown utilizado pelo chatbot.

## Alterações técnicas

- **Frontend:** Criados e atualizados `src/features/layout/ChatAssistant.jsx`, `chatbotResponses.js` e `chatbot-context.md`; integrado o assistente em `src/pages/Home.jsx`; removido o uso de `WhatsAppFloat.jsx`.
- **Backend:** O servidor Node local foi movido para `src/index.js`. Continua oferecendo apenas `GET /api/health`; as demais rotas da API não estão implementadas.
- **Banco de dados:** Nenhuma alteração.
- **Infraestrutura/deploy:** Ajustados o proxy `/api` do Vite e os caminhos dos scripts locais. Nenhuma publicação ou alteração de workflow de deploy foi realizada.
- **Dependências:** Ajustados `package.json` e `pnpm-lock.yaml` nos commits do período. Não foi introduzido provedor de IA nem nova dependência para o chatbot.

## Correções realizadas

- Corrigido o encaminhamento do chatbot: antes, “Falar com a equipe” respondia com instruções e o link abria uma mensagem genérica, sem preservar o briefing. Agora o WhatsApp é aberto com o resumo já preenchido.
- Corrigida a localização do servidor: os scripts ainda apontavam para `server/index.js` depois da remoção da pasta. Agora usam `src/index.js`.
- Atualizadas referências de documentação que ainda descreviam `server/index.js` como existente.
- Removidas descrições antigas de pastas vazias do servidor para não sugerir que a estrutura removida permanece no projeto.

## Limites e pendências

- O chatbot usa correspondência local por regras e respostas predefinidas; não compreende livremente qualquer pergunta como um modelo de IA.
- O servidor local permanece um placeholder: autenticação, orçamentos e demais endpoints ainda não existem.
- A aba compartilhada do navegador integrado do VS Code foi observada em branco, embora uma execução local separada tenha renderizado o site sem erros de JavaScript. A causa específica da aba do VS Code não foi identificada nem confirmada como corrigida.
- O typecheck do projeto falha com erros em módulos de autenticação, serviços e hooks. Nenhum erro do chatbot apareceu no resultado verificado; os erros existentes precisam ser triados separadamente.
- O build continua exibindo aviso de chunk JavaScript acima de 500 kB.
- A versão não foi publicada nem criada como tag Git.

## Próximos passos

2. Corrigir os erros existentes do typecheck em autenticação, serviços e hooks.
